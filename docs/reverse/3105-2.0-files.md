# 3105 官方 2.0 Files 逆向记录

- 目标：`3105-2.0-build8-20260914-125906-unsigned.ipa`
- 下载：`https://github.com/YangJiiii/3105/releases/download/v2.0/3105-2.0-build8-20260914-125906-unsigned.ipa`
- Bundle：`com.apple.mobile.MobileHouseArrest`，版本 `2.0 (8)`
- 方法：`unzip` → `plutil -convert` → `nm` + `swift-demangle` → `radare2` 反汇编
- 二进制未剥离符号（26,331 个）

## 1. 类型结构

| 官方符号 | 作用 |
|---|---|
| `AppDataBrowserView` | Files 首页（分组列表），内部有 `fileLocations` |
| `ApplicationBrowserView` | Application 子页（App 列表），`init(tabSession:)`、`load()`、`filteredApps` |
| `FilesRootLocation` | 首页位置枚举 |
| `FileFavoritesStore` | 收藏夹存储（`ObservableObject`） |
| `FileFavorite` | 收藏项（`Codable, Identifiable, Hashable`） |

## 2. `FilesRootLocation`

`strings` 精确匹配到三个 rawValue：

```text
application
appGroup
systemAppGroup
```

`AppDataBrowserView.fileLocations` 的返回类型：

```text
TupleView<(
  Section<Text, ...>,
  Section<Text, ForEach<[FilesRootLocation], String, ...>, Text>
)>
```

即首页 = Workspace section + `ForEach(FilesRootLocation.allCases)` section（带 footer）+ Favorites section。

## 3. 共享容器路径

```text
/var/mobile/Containers/Shared/AppGroup
/var/containers/Shared/SystemGroup
```

二进制中还有 `_systemAppGroupIdentifiers` / `systemAppGroupIdentifiers`，用于系统共享组筛选。

## 4. 收藏夹

`FileFavorite.CodingKeys.stringValue` 反汇编确认字段：

```text
"id" / "path" / "name"
```

`FileFavorite.init(from:)` 调用 `Foundation.UUID` 的 metadata，确认 `id` 类型为 `UUID`。

`FileFavoritesStore` 方法（地址）：

```text
add(path:name:)       0x1002cefec
contains(path:)       0x1002cee84
favorites.getter      0x1002cf2a0
load()                0x1002cfc70
save()                0x1002cfe20
shared                0x10040080a0
```

`load()` 反汇编：`UserDefaults.standard` → `data(forKey:)` → `JSONDecoder.decode([FileFavorite])`。
`save()`：`JSONEncoder.encode([FileFavorite])` → `UserDefaults.standard.set(data, forKey:)`。
存储 key 字符串：`fileBrowserFavorites`。

## 6. 结论

- 公开源码的 `AppDataBrowserView` 是 1.x 的 App 列表；官方 2.0 把它重命名为 `ApplicationBrowserView`，新的 `AppDataBrowserView` 是分组首页。
- 复刻方式：新建 `FilesHomeView`（Workspace / FilesRootLocation / Favorites）、`SharedContainerBrowser`、`FileFavoritesView`；`FileFavoritesStore` 使用官方同名字段和 UserDefaults key，覆盖安装时可直接读取旧收藏数据。
